# AI Builder 0.8.0 — AI Freeform Building

## 0.8.0 — настоящий свободный генератор, без шаблонов

**Теперь F7 и `/ai build` НЕ используют заранее запрограммированные дома и замки.**
Вместо операции `house` или `castle` нейросеть должна вернуть оригинальный
список геометрических операций: фундаменты, стены, башни, проёмы, двери,
окна, крыши, интерьер. Для каждой части ИИ самостоятельно задаёт координаты
и материалы, исходя из текущего описания. Мод проверяет JSON, свойства
блоков, границы, лимиты и выполняет операции в игровом мире.

**Важное различие:**
- **F7 / `/ai build`:** настоящий AI Freeform, новый чертёж для каждого
  запроса. Использует Polza/OpenAI и может расходовать API-токены.
- **`/ai house`, `/ai house modern`, `/ai castle`:** старые
  заготовленные локальные демонстрации для проверки игрового движка,
  без API. Они НЕ применяются к обычным запросам F7.

Если модель возвращает только `house`/`castle` вместо оригинальных
координат, мод отклоняет такой ответ и, если включён параметр
`retryMalformedJson`, запрашивает новый план один раз. Повторный
API-запрос может быть платным.

Последний успешно сгенерированный и проверенный чертёж сохраняется локально:
`config/aibuilder/last-generated-plan.json`. Это конкретные операции,
созданные ИИ для твоего запроса, а не содержимое встроенного шаблона.
При новой успешной генерации этот файл перезаписывается. Не публикуй
содержимое, если описание постройки конфиденциально.

Качество и уникальность результата зависят от модели, описания и
ограничений движка. Здесь пока нет полноценной оценки рендера/проходимости:
автоматическое тестирование компиляции не гарантирует красивую постройку.
Строй в тестовом творческом мире и сохраняй резервную копию.


## Установка
Minecraft Java 1.21.1, Fabric Loader, Fabric API, Java 21.
Открой папку `mods` именно своего профиля LabyMod, удали старые JAR
AI Builder и положи `aibuilder-fabric-0.8.0.jar`. Перезапусти игру.

## Управление
- **F8** или `/ai key` — окно Polza AI/OpenAI с ключом и моделью.
- **F7** или `/ai prompt` — отдельный **многострочный редактор** промпта
  до 12000 символов (вставка Ctrl+V), без ограничения длины игрового чата.
- `/ai build <описание>` — короткий промпт обычным чатом.
- **`/ai house`** — тестовый двухэтажный дом с настоящими дверями,
  кроватями, крышей из ступеней, окнами, мебелью и лестницей — БЕЗ API.
- `/ai demo` — тестовый спавн БЕЗ API.
- `/ai status` — прогресс, `/ai cancel` — остановить/откатить,
  `/ai undo` — отменить последнюю постройку.

Режим: только **одиночный мир, креатив**.
Рекомендуется сделать резервную копию мира.

## Пример подробного промпта (в F7)
Построй большой, реалистичный средневековый двухэтажный дом
размером 21×17 блоков. Сделай каменный фундамент, стены
из дубовых брёвен и светлого дерева с тёмными декоративными балками.
Обязательно поставь настоящие открывающиеся двери спереди и сзади,
свободные дверные проёмы высотой 2 блока, окна со стеклянными
панелями и красивыми рамами. Крыша высокая двускатная из
ступеней тёмного дуба с карнизами. Внутри два проходимых этажа,
настоящая лестница с площадкой, гостиная со столом и стульями,
две спальни с кроватями, книжные полки, ковры и фонари.
Вокруг дома: тропинка из камня, сад, ограда, деревья и цветы.
Нельзя заполнять комнаты сплошными блоками, перекрывать проходы,
ставить декоративные предметы вместо функциональных дверей.
Сохраняй пропорции и продуманную архитектуру.

## Важно
Это улучшенный **геометрический строительный движок**, а не WorldEdit
или готовый генератор профессиональных карт. Удалять старые версии JAR
обязательно. Успешная сборка не подтверждает тестирование внутри LabyMod.

Ключ Polza хранится локально (`config/aibuilder/polza-key.txt`),
ключ OpenAI отдельно (`api-key.txt`). Не публикуй их.

## Исправление ошибок ИИ
Начиная с версии 0.8.0, мод исправляет распространённые выдуманные
названия блоков в JSON-планах без повторного платного обращения к API.
Например, `light_oak_planks` → `birch_planks`, `pale_oak_planks`
→ `birch_planks`, `glass_panels` → `glass_pane`.
Некорректные или опасные неизвестные ID по-прежнему отклоняются.

## Исправление «MalformedJsonException» (0.8.0)
Мод пытается без дополнительных API-вызовов исправить простой синтаксис ответа ИИ:
обёртки из Markdown, завершающие запятые, пропущенные запятые между операциями,
пропущенные двоеточия в известных полях.
Для моделей OpenAI GPT-4.1/4o в Polza AI запрашивается JSON-режим,
если провайдер поддерживает его; при HTTP 400 выполняется обычный запрос.
Если план по-прежнему повреждён или обрезан, мод может **один раз повторить
платную генерацию** с более короткими требованиями. Чтобы отключить повтор:
`config/aibuilder/config.json` → `"retryMalformedJson": false`.
Старые файлы настроек без этого параметра по умолчанию допускают один повтор.
Совсем повреждённые планы никогда не строятся частично.

## Исправление «Неизвестная форма: lantern» (0.8.0)

Раньше ИИ иногда путал название типа операции и название блока,
например писал `"type":"lantern"`, хотя правильно:
`"type":"block","block":"lantern"`.

Теперь мод автоматически исправляет поддерживаемые блочные типы
(`lantern`, `soul_lantern`, `torch`, `glass_pane`, `oak_stairs`,
`oak_trapdoor`, `bookshelf`, `red_carpet` и др.).
Для `oak_door` и `red_bed` используются специальные операции
с двумя блоками. Также понимаются некоторые понятные имена форм:
`window`, `wall`, `roof`, `stairs`, `pillar`, `floor`, `light`.
Это локальное исправление и не расходует дополнительные API-токены.
Неизвестные формы и запрещённые блоки по-прежнему отклоняются.

## Новое в 0.8.0 — исправление flower_pot и более качественные модели
В игре появилась команда `/ai version`, которая показывает фактически загруженную
версию мода. Если команда неизвестна, используется старая сборка или активен
другой профиль LabyMod. Удалите ВСЕ старые aibuilder JAR из активной папки mods.

Типы `flower_pot`, `flowerpot`, `pot`, `potted_flower` и `flower`
обрабатываются как операции установки разрешённых декоративных блоков.
Проверяется автоматически тестами.

В меню F8 → Polza AI появились кнопки моделей:
- Эконом: `openai/gpt-4.1-mini` (дешевле, часто делает простые проекты).
- Рекомендовано: `openai/gpt-5.4-mini` (для более продуманных проектов).
- Точность: `openai/gpt-4.1` (для строгого следования инструкциям).
Нажмите нужную кнопку, затем **Только настройки**. Снова вводить API-ключ
не нужно. Новые установки начинают с GPT-5.4 mini; у существующих пользователей
ранее выбранная модель НЕ меняется без явного выбора.
GPT-5.4 mini может быть дороже, чем 4.1-mini, при том же запросе.
Для сложных моделей возможны несовместимости конкретного API-маршрута Polza.
При ошибке HTTP 400 проверьте модель или попробуйте GPT-4.1.

Уточнены инструкции для ИИ: сначала геометрия, проходы и крыша, затем декор.
Любой план может оказаться несовершенным: проверяйте в тестовом мире.

## Исправление свойств блоков в версии 0.8.0
ИИ иногда добавляет неверные свойства, например `axis=x` к
`smooth_stone_slab`. Теперь неподдерживаемые необязательные свойства
отбрасываются, а валидный блок всё равно ставится. Проверяются
нативные свойства Minecraft, поэтому `axis` по-прежнему корректно
применяется к брёвнам, а `slab_type=top` к плитам. Обязательные
свойства дверей, кроватей и процедурных крыш всё ещё проверяются
строго. Изменены также инструкции для ИИ.

После установки новой версии убедись командой `/ai version`, что
выведено `0.8.0`. Если там старая версия, удали старые .jar из
папки модов активного профиля LabyMod и перезапусти Minecraft.

## Новое в 0.8.0: точные координаты домов

Самая частая причина кривых построек — не материал, а неверные координаты
дверей, окон, крыши и лестницы в JSON от нейросети. Поэтому добавлен режим
**параметрического дома**: вместо десятков вручную рассчитанных координат
ИИ выдаёт одну операцию `type: house`. Мод сам рассчитывает:
фундамент, ровный пол, четыре стены, уголковые опоры, двускатную крышу
со ступенями и заполненными фронтонами, симметричные окна и рабочие двери.
При двух этажах создаются перекрытие, лестничный марш и проход в перекрытии;
добавляются мебель и дорожка к входу.

Для проверки без оплаты API используй **`/ai house`**. Теперь эта команда
генерирует дом из новой схемы (только креатив и одиночная игра).

Пример схемы, которую теперь понимает мод:
```json
{
  "name":"Двухэтажный коттедж",
  "operations":[
    {
      "type":"house","x":6,"y":0,"z":6,"w":17,"d":13,
      "floors":2,"front":"north","foundation":"stone_bricks",
      "wall":"birch_planks","floor":"oak_planks",
      "beam":"stripped_oak_log","roof":"dark_oak_stairs",
      "door":"spruce_door","glass":"glass_pane"
    }
  ]
}
```
Допустимые размеры: w=11–25, d=9–23, floors=1 или 2; `front` —
север/юг/восток/запад (`north/south/east/west`). Описание обычного
дома через F7 теперь просит ИИ выбирать этот безопасный способ построения.
Для больших замков, городов и необычных фигур остаются обычные
геометрические операции (результат менее предсказуем).

Дополнительная защита от ошибок: `stage` теперь определяет приоритет
перекрытия координат. Стена из этапа walls не может затереть
стекло окна из details или вырезанный вход из openings просто потому,
что была записана в JSON позднее. Двери и кровати сохраняют обе части
при попытках перекрытия декоративными блоками.

Все прежние команды и модели сохранены. GPT-4.1 можно не менять:
этот режим исправляет именно геометрию, а не выбор нейросети.
Нужно полностью перезапустить Minecraft и проверить `/ai version` → 0.8.0.
Сначала сделай резервную копию мира и протестируй в отдельном мире.

## 0.8.0 — разные дома вместо одного шаблона

В предыдущей версии операция `house` строила почти один и тот же дом.
Теперь у параметрической системы **семь стилей**: средневековый, современный,
японский, скандинавский, альпийский, лесной и кирпичный. Различаются не только
материалы, но и форма крыш (двускатная, вальмовая, плоская), типы окон,
фасады, входные крыльца, балконы, дымоходы и ландшафт.

### Проверить бесплатно, без API-ключа

Открой одиночный мир, творческий режим. `/ai house` без параметров остаётся
простой демонстрацией **medieval** (поэтому он выглядит одинаково!).
Для других построек используй:

- `/ai house medieval` — фахверк с двускатной крышей
- `/ai house modern` — современная вилла с плоской крышей
- `/ai house japanese` — японский дом с вальмовой крышей
- `/ai house nordic` — скандинавский дом
- `/ai house alpine` — горное шале с балконом
- `/ai house rustic` — маленький лесной коттедж с садом
- `/ai house brick` — кирпичный особняк с вальмовой крышей

Всё ещё нужно достаточно свободного места для дома и кровли. Можно
отменить последнюю постройку командой `/ai undo`.

### Генерация по обычному запросу (F7)

При запросе «японский дом» мод сам выставляет style=japanese и roof_style=hip,
при «современная вилла» — style=modern и roof_style=flat; аналогично работает
для северного, альпийского и лесного дома. Учитываются явно указанные
размеры 17×13, количество этажей, просьбы о крыльце, балконе, дымоходе,
саде, типе крыши и окон. Если модель скопировала из примера стандартную
крышу, локальный обработчик приведёт её к нужному стилю без затрат API.
Сами стены, окна, лестницы, крыши и входы вычисляются движком по размерам.

Новое JSON-поле `style`: medieval, modern, japanese, nordic, alpine,
rustic, brick. Дополнительно: `roof_style`: gable, hip, flat;
`window_style`: classic, narrow, wide, tall; `porch`, `balcony`,
`chimney`, `garden`: true или false; `roof_block` для плоской крыши.

Форма/оформление — не фотореалистичная копия стиля: японский дом всё равно
строится в рамках геометрических ограничений Minecraft и модификатора house.
Необычные сооружения требуют дополнительных примитивов. Для безопасности
сделай резервную копию мира перед экспериментами.

Установи только один `aibuilder-fabric-0.8.0.jar`, перезапусти игру
и проверь `/ai version` → 0.8.0.

## 0.8.0 — замки и длинные запросы

F7 поддерживает 12000 символов вместо 1800. Увеличение длины запроса может повысить расходы на API.

Мод исправляет нулевые размеры и безопасно ограничивает чрезмерно большие операции. Границы мира и суммарный лимит блоков сохраняются.

`/ai castle` строит демонстрационный замок 35x35 без API: четыре башни, стены, ворота и донжон. При генерации через F7 модель может использовать операцию `castle` с размерами 25–39 блоков. Проверяй сначала в тестовом мире.
