# AI Builder 0.4.5 Advanced Building

## Установка
Minecraft Java 1.21.1, Fabric Loader, Fabric API, Java 21.
Открой папку `mods` именно своего профиля LabyMod, удали старые JAR
AI Builder и положи `aibuilder-fabric-0.4.5.jar`. Перезапусти игру.

## Управление
- **F8** или `/ai key` — окно Polza AI/OpenAI с ключом и моделью.
- **F7** или `/ai prompt` — отдельный **многострочный редактор** промпта
  до 1800 символов (вставка Ctrl+V), без ограничения длины игрового чата.
- `/ai build <описание>` — короткий промпт обычным чатом.
- **`/ai house`** — тестовый двухэтажный дом с настоящими дверями,
  кроватями, крышей из ступеней, окнами, мебелью и лестницей — БЕЗ API.
- `/ai demo` — тестовый спавн БЕЗ API.
- `/ai status` — прогресс, `/ai cancel` — остановить/откатить,
  `/ai undo` — отменить последнюю постройку.

Режим: только **одиночный мир, креатив**.
Рекомендуется сделать резервную копию мира.

## Пример подробного промпта (в F7)
Построй большой, реалистичный средневековый двухэтажный дом
размером 21×17 блоков. Сделай каменный фундамент, стены
из дубовых брёвен и светлого дерева с тёмными декоративными балками.
Обязательно поставь настоящие открывающиеся двери спереди и сзади,
свободные дверные проёмы высотой 2 блока, окна со стеклянными
панелями и красивыми рамами. Крыша высокая двускатная из
ступеней тёмного дуба с карнизами. Внутри два проходимых этажа,
настоящая лестница с площадкой, гостиная со столом и стульями,
две спальни с кроватями, книжные полки, ковры и фонари.
Вокруг дома: тропинка из камня, сад, ограда, деревья и цветы.
Нельзя заполнять комнаты сплошными блоками, перекрывать проходы,
ставить декоративные предметы вместо функциональных дверей.
Сохраняй пропорции и продуманную архитектуру.

## Важно
Это улучшенный **геометрический строительный движок**, а не WorldEdit
или готовый генератор профессиональных карт. Удалять старые версии JAR
обязательно. Успешная сборка не подтверждает тестирование внутри LabyMod.

Ключ Polza хранится локально (`config/aibuilder/polza-key.txt`),
ключ OpenAI отдельно (`api-key.txt`). Не публикуй их.

## Исправление ошибок ИИ
Начиная с версии 0.4.5, мод исправляет распространённые выдуманные
названия блоков в JSON-планах без повторного платного обращения к API.
Например, `light_oak_planks` → `birch_planks`, `pale_oak_planks`
→ `birch_planks`, `glass_panels` → `glass_pane`.
Некорректные или опасные неизвестные ID по-прежнему отклоняются.

## Исправление «MalformedJsonException» (0.4.5)
Мод пытается без дополнительных API-вызовов исправить простой синтаксис ответа ИИ:
обёртки из Markdown, завершающие запятые, пропущенные запятые между операциями,
пропущенные двоеточия в известных полях.
Для моделей OpenAI GPT-4.1/4o в Polza AI запрашивается JSON-режим,
если провайдер поддерживает его; при HTTP 400 выполняется обычный запрос.
Если план по-прежнему повреждён или обрезан, мод может **один раз повторить
платную генерацию** с более короткими требованиями. Чтобы отключить повтор:
`config/aibuilder/config.json` → `"retryMalformedJson": false`.
Старые файлы настроек без этого параметра по умолчанию допускают один повтор.
Совсем повреждённые планы никогда не строятся частично.

## Исправление «Неизвестная форма: lantern» (0.4.5)

Раньше ИИ иногда путал название типа операции и название блока,
например писал `"type":"lantern"`, хотя правильно:
`"type":"block","block":"lantern"`.

Теперь мод автоматически исправляет поддерживаемые блочные типы
(`lantern`, `soul_lantern`, `torch`, `glass_pane`, `oak_stairs`,
`oak_trapdoor`, `bookshelf`, `red_carpet` и др.).
Для `oak_door` и `red_bed` используются специальные операции
с двумя блоками. Также понимаются некоторые понятные имена форм:
`window`, `wall`, `roof`, `stairs`, `pillar`, `floor`, `light`.
Это локальное исправление и не расходует дополнительные API-токены.
Неизвестные формы и запрещённые блоки по-прежнему отклоняются.

## Новое в 0.4.5 — исправление flower_pot и более качественные модели
В игре появилась команда `/ai version`, которая показывает фактически загруженную
версию мода. Если команда неизвестна, используется старая сборка или активен
другой профиль LabyMod. Удалите ВСЕ старые aibuilder JAR из активной папки mods.

Типы `flower_pot`, `flowerpot`, `pot`, `potted_flower` и `flower`
обрабатываются как операции установки разрешённых декоративных блоков.
Проверяется автоматически тестами.

В меню F8 → Polza AI появились кнопки моделей:
- Эконом: `openai/gpt-4.1-mini` (дешевле, часто делает простые проекты).
- Рекомендовано: `openai/gpt-5.4-mini` (для более продуманных проектов).
- Точность: `openai/gpt-4.1` (для строгого следования инструкциям).
Нажмите нужную кнопку, затем **Только настройки**. Снова вводить API-ключ
не нужно. Новые установки начинают с GPT-5.4 mini; у существующих пользователей
ранее выбранная модель НЕ меняется без явного выбора.
GPT-5.4 mini может быть дороже, чем 4.1-mini, при том же запросе.
Для сложных моделей возможны несовместимости конкретного API-маршрута Polza.
При ошибке HTTP 400 проверьте модель или попробуйте GPT-4.1.

Уточнены инструкции для ИИ: сначала геометрия, проходы и крыша, затем декор.
Любой план может оказаться несовершенным: проверяйте в тестовом мире.

## Исправление свойств блоков в версии 0.4.5
ИИ иногда добавляет неверные свойства, например `axis=x` к
`smooth_stone_slab`. Теперь неподдерживаемые необязательные свойства
отбрасываются, а валидный блок всё равно ставится. Проверяются
нативные свойства Minecraft, поэтому `axis` по-прежнему корректно
применяется к брёвнам, а `slab_type=top` к плитам. Обязательные
свойства дверей, кроватей и процедурных крыш всё ещё проверяются
строго. Изменены также инструкции для ИИ.

После установки новой версии убедись командой `/ai version`, что
выведено `0.4.5`. Если там старая версия, удали старые .jar из
папки модов активного профиля LabyMod и перезапусти Minecraft.
