# DDNetCraft Fabric 0.2.0

Мод для **Minecraft Java Edition 1.21.1**, вдохновлённый DDNet. Это именно **Fabric-мод**, не Bukkit/Paper плагин.

## Механики
- Хук: ПКМ предметом по блоку до 26 блоков, повторный ПКМ отпускает.
- Хук по игроку: ПКМ по товарищу тянет его к тебе, помогает разморозить.
- Предмет «Разморозка»: ПКМ по замороженному игроку.
- Синий лёд = FREEZE; морской фонарь = UNFREEZE.
- Лаймовый бетон = старт; золотой блок = чекпоинт; изумрудный блок = финиш.
- Команды: `/ddnet kit`, `/ddnet reset`, `/ddnet status`, `/ddnet help`.

## Как скачать JAR
1. Открой вкладку **Actions** репозитория.
2. Выбери workflow **Build Fabric mod** и успешный запуск.
3. Скачай артефакт **DDNetCraft-Fabric-1.21.1**.
4. Извлеки `ddnetcraft-fabric-0.2.0.jar` и положи в `.minecraft/mods`.
5. Нужны Fabric Loader для 1.21.1 и Fabric API версии для 1.21.1.

Если сборка красная, JAR не готов — нужно исправить ошибку в логе. Проект пока не испытан в игре, точная физика DDNet не воспроизведена.

Локальная сборка: Java 21 и Gradle 8.8, команда `gradle build`. На сервере Fabric мод тоже необходим.
