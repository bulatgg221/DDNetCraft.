# DDNetCraft — одиночный DDRace (Fabric 1.21.1)

**Это клиентский мод Minecraft Java 1.21.1.** Для запуска необходимы Fabric Loader, Fabric API и Java 21.

## Возможности MVP
- Отдельный режим DDNet, включается клавишей **G** или командой `/ddnet on`.
- 2D-движение вдоль X/Y, гравитация, ускорение и трение, двойной прыжок.
- **Q** (удерживать): хук с полётом, зацепом и притяжением. Отпускание отменяет хук.
- **J** (удерживать): стрельба. **1 / 2 / 3**: Pistol / Grenade / Laser.
- Граната взрывается и отталкивает игрока; лазер до двух раз отражается от стен и притягивает к конечной точке луча.
- **R** — рестарт уровня; таймер, HUD, зоны смерти/заморозки, финиш, чекпоинты и зона слабой гравитации.
- JSON-карта из `config/ddnetcraft/maps/training.json`; локальные настройки физики в `config/ddnetcraft/physics.json`.

## Установка
1. Установите Minecraft Java 1.21.1 с **Fabric Loader**.
2. Положите **Fabric API 1.21.1** и JAR DDNetCraft в `.minecraft/mods`.
3. Запустите обычный **одиночный мир** и выполните `/ddnet on` или нажмите G.
4. Нажмите G ещё раз для выхода. Для собственной карты: `/ddnet load <имя>` — имя файла без `.json`.
5. Команды клиента: `/ddnet`, `/ddnet on`, `/ddnet off`, `/ddnet restart`, `/ddnet load training`, `/ddnet reloadconfig`.

### Формат карты
JSON: поля `name`, `spawn: {x,y}`, массив строк `rows` **сверху вниз**. Ширина всех строк одинаковая.

| Символ | Зона |
| --- | --- |
| `.` | Воздух |
| `#` / `H` | Твёрдый блок, можно зацепиться |
| `U` | Твёрдый блок, хук не цепляется |
| `K` | Моментальная смерть |
| `F` | Freeze |
| `E` | Finish |
| `C` | Checkpoint |
| `L` | Зона малой гравитации |

В ресурсах мода есть тег `ddnet:unhookable` для настоящих блоков мира (по умолчанию bedrock и obsidian).

## Технические ограничения
- **Клиентская виртуальная карта**: цветные проволочные блоки накладываются на одиночный мир, не заменяя и не изменяя настоящие блоки. Коллизии карты вычисляются на клиенте. Для ясного обзора лучше использовать пустую или плоскую локацию.
- Управление — 2D X/Y, обычная камера Minecraft остаётся свободной. Это не точная камера Teeworlds.
- Значения параметров конфига — **DDNet-пиксели/тик**, конвертация 32 пикселя = 1 блок. Это упрощённая, а не побитно точная физика DDNet.
- В Minecraft даже одиночный мир использует **интегрированный сервер и стандартный сетевой протокол**. Мод не добавляет пользовательских пакетов и серверной логики, но при дальних перемещениях/наложении на реальные блоки возможны коррекции положения со стороны ванильного сервера. Для полностью надёжной замены серверных коллизий потребовалась бы более глубокая интеграция.
- Обычный режим Minecraft сохраняется после выключения DDNet. Состояние DDNet не сохраняется между перезапусками.
- Не рассчитан на LabyMod или серверы; для тестирования используйте чистый Fabric.
- Это **MVP исходников**: успешный Gradle build подтверждает компиляцию, но не заменяет функционального тестирования в Minecraft.

## Сборка JAR
GitHub Actions → **Build Fabric mod** → успешный запуск → **Artifacts** → **DDNetCraft-Solo-1.21.1**.

Локально: Java 21 и Gradle 8.8, команда `gradle build`.
